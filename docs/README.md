# Docs navigation

The authoritative runtime is **native Rust**, in `../rust/src/`. Start with the [root README](../README.md), [AGENTS.md](../AGENTS.md), and [Design Principles](../DESIGN-PRINCIPLES.md). Use [native Rust tests](../rust/tests/) for current regression coverage.

`RUST2_*` documents and older feature specifications are **migration and historical evidence**, not instructions to rebuild or execute the removed Node.js source. Node `src/`, `test/`, npm packaging and head-to-head fixtures no longer exist in current `main`. CLI/daemon deployment uses installed Rust binaries.
